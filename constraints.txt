#      requirements.txt (daharness/requirements.txt). This section installs

#   2. TRANSITIVE CEILINGS — upper bounds on packages pulled in transitively
#      (not carried by the freeze, which deliberately leaves them open).
#      Keep this section rare — a pinned transitive can conflict with future
#      apt packages on upgrade day.
#
# Mirror additions/removals from daharness/requirements.txt BY HAND and one
# commit at a time — the diff of this file against the freeze is the record.
#
# Pre-flight drift check (the "what's satisfied vs not" diff — should
# always resolve clean):
#   pip install --dry-run -r requirements.txt -c constraints.txt
# Then install for real into the venv + import smoke test.
